# AI Workflow Canvas（开源）

> GitHub：https://github.com/qw66668888/ai-infinite-canvas

一个深色、无限缩放的 **AI 图像节点工作流画布**。它不是便签白板：参考图、提示词、生成结果和最终输出都以节点呈现，并通过端口连线组成可运行的图生图流程。

## 画布能力
- 图片素材节点：点击或拖入 JPG / PNG / WebP，支持多图输入
- 提示词节点：编写改图要求，连接任意数量的参考图后运行
- 结果节点：生成结果自动写回，可下载或复制成新的参考图节点
- 标注修改：在参考图或结果图上涂抹/框选修改区域，填写说明后随图生图一起发送给方舟
- 输出节点：自动预览上游结果，形成最终成品
- 视频节点：Seedance 图生视频、视频编辑、任务状态轮询与结果播放
- 曲线连线：从节点右侧圆点拖到另一节点左侧；双击连线删除
- 无限画布：拖拽平移、滚轮/触控板缩放、全览和自动排列；使用浏览器原生清晰缩放，缩小后文字、边框和图片不会因整体拉伸而发虚
- 节点操作：拖拽移动、拖动右下角自由调整大小、重命名、更换图片、删除、快捷键运行
- 自动保存：工作流保存在浏览器本地；超大图片超出存储上限时仍保留在当前会话

打开后会看到一套完整示例：人物、家具、空间与氛围参考图连接到提示词节点，再流向生成结果和最终输出。示例图片位于 `public/demo/`，可随时删除或替换。

## 本地运行

### 最简单：桌面“AI 画布”快捷方式
双击桌面的 **AI 画布** 即可。服务未启动时会自动在后台启动，然后打开浏览器；如果检测到旧版服务，会先自动重启再打开画布。项目目录里的 `open-canvas.bat` 是同一功能。

### 方式一：免构建静态版（推荐）
双击 `start-canvas.bat`，保持窗口开启，浏览器打开 http://localhost:5180 。

这个方式不调用 Vite / esbuild，适合出现 `spawn EPERM` 或被安全软件拦截子进程的电脑。修改源码后运行一次 `build-native.bat` 即可重新生成。

### 方式二：Vite 开发模式
```bash
cd ai-infinite-canvas
npm install
npm run dev
```

打开 http://localhost:5180 。Windows 也可以双击 `start-dev-vite.bat`，保持窗口开启。

如果 5180 端口被旧进程占用，请先关闭之前的启动窗口再重新运行。

## 模型配置
点击右上角设置按钮：

1. **画布名称 / 副标题 / Logo**：改成你自己的品牌名称并上传 Logo（透明底 PNG 或 SVG 效果最好），保存后左上角和浏览器标签页会立即更新
2. **连线配色**：默认“多彩流光”，每条连线内部使用多色渐变且相邻连线错开主色；也可切换“单色流光”，使用预设色、取色器或十六进制色值自定义
3. **接口地址**：`https://ark.cn-beijing.volces.com/api/v3`
4. **API Key**：火山方舟 API Key
5. **图生图模型 / 接入点**：填 Seedream / SeedEdit 的模型 ID 或 `ep-...` 推理接入点 ID
6. **视频模型 / 接入点**：填 Seedance 的模型 ID 或 `ep-...` 推理接入点 ID
7. **输出尺寸**：可选“按原图尺寸生成”或“自定义尺寸”。自定义范围 256–4096 像素，会按 `宽x高` 发送给方舟；原图超过 4096 时自动等比缩到 4K 上限。**电商主图固定 1440x1440**，可在下面的“主图尺寸”修改；**长图海报每屏按对应原图尺寸生成**（单次不超过 4096px，22 屏建议逐屏生成后拼接）
8. **商品事实锁定**：填写商品固定结构、颜色、配件、防滑垫和品牌卡扣位置；运行电商/商品类提示词时会自动追加到提示词，避免不同图片里的商品结构跑偏

画布名称保存在当前浏览器。留空名称时会恢复默认的 `AI Workflow`；副标题留空则隐藏。顶部“工作流”后面的名称仍可单独点击编辑，用于区分不同工作流。

也可通过 `.env.local` 配置：
```bash
VITE_OPENAI_BASE_URL=https://ark.cn-beijing.volces.com/api/v3
VITE_OPENAI_API_KEY=你的密钥
VITE_EDGE_COLOR=#69dcff
VITE_EDGE_COLOR_MODE=multi
VITE_IMAGE_MODEL=ep-xxxxxxxx
VITE_VIDEO_MODEL=ep-zzzzzzzz
VITE_OPENAI_MODEL=ep-yyyyyyyy
```

修改 `.env.local` 后需要重启服务。`VITE_*` 会被打包进前端，公开部署时请通过自己的后端代理 API，避免泄露长期密钥。

> 火山方舟目前最高支持 4K 输出；需要 8K 时，建议下载 4K 结果后再做无损放大。

## 工作流用法
1. 在左侧添加或拖入图片素材，点击节点右上角“更换图片”。
2. 添加提示词节点，把每张参考图的右侧圆点拖到提示词节点左侧输入端口。
3. 填写提示词，点击节点里的“运行”或右上角“运行工作流”。
4. 生成结果自动进入结果节点，并同步到输出节点。
5. 对结果使用“复制为参考图”，即可继续做下一轮图生图。

## 电商整套（3 张主图 + 长图海报）
1. 先选中已经上传好的商品图片节点，再点击顶部“电商套图”。如果没有选中图片，会自动创建一个“商品原图”节点，上传商品图即可。
2. 画布会自动创建 4 个提示词节点：白底主图、场景主图、细节主图和长图海报，并分别连接结果节点。
3. 如需锁定全车 CHAOPAI 品牌卡扣，点击顶部“卡扣参考”，会自动加入图二参考图并连接电商提示词；生成时只把它当作卡扣、字标和金属质感的参考，不会复制特写构图。
4. 在提示词末尾补充商品名称、核心卖点、目标人群和品牌风格。
5. 点击“电商主图 A”节点里的“生成套图”，会依次生成 3 张 1:1 主图（默认 1440×1440）和 1 张按参考图尺寸生成的长图海报。
6. 提示词会尽量保持商品外形、颜色、材质和 logo 不变；长图海报会预留各分区文案留白，不直接生成容易乱码的文字，可在设计软件中继续排版标题和卖点。

## 标注修改
1. 鼠标移到图片节点或生成结果节点上，点击图片左上角或标题栏里的“标注修改”。
2. 用“涂抹”或“框选”圈出需要修改的区域，可切换红、黄、蓝、绿标注色和笔刷大小。
3. 在“修改说明”里写清要改成什么，例如“把红色框出的门换成深色木门，其他区域保持不变”，然后保存。
4. 把标注后的图片节点连接到提示词节点，填写整体提示词并运行。画布会自动把标注图和修改说明一起发送给 Seedream / SeedEdit。

如果想重新标注，点击“继续标注”；想恢复原图，在标注弹窗里点击“清除已保存标注”。标注线只是位置提示，提示词会要求模型不要把它们保留在最终画面中。

## 主图排版（带中文文案）
1. 先在画布里生成无字商品底图（电商主图 A/B/C 任意一张），满意后点结果节点右上角下载。
2. 点击顶部“主图排版”，打开 `http://localhost:5180/main-image.html`。以后也可以直接双击项目根目录的 `open-canvas.bat` 启动本地服务，再打开这个页面；黑色服务窗口保持开启即可，关闭窗口就会停止服务。如果提示端口被占用，先关闭旧的 AI Canvas Server 窗口。
3. 上传刚下载的底图，页面会自动套用“适用于享界 S9/S9T / 原车色双层脚垫 / 原车同色·防尘防污·防滑耐磨”等文案和底部四个卖点条。
4. “画面清晰度”可调锐化强度；标准、清晰、超清是三个快捷档位。页面会提示原图分辨率是否足够，输出始终保持 1440×1440。
5. 如果底图已经带旧文字，点“框选旧文字”，在画布上框住那行字，直接点“原样抠字”。它按原图像素抠出，保留原字体、渐变、描边和阴影；抠出后可拖动、改缩放、恢复或删除。只有确实要改文字内容时，才用“识别旧文字 / 识别改字”生成普通文字层，再改字、改色、改字号。多个候选框可用“全部原样抠字”批量处理。
6. 可直接修改标题、副标题和卖点文字，预览会实时更新；横幅可增删、调宽高和颜色。
7. 局部改色是“点选式”：开启后在脚垫上点一下即可选同色区域，不用涂抹。氛围灯是“点节点连线”：依次点灯带节点，再点“完成当前灯线”，不做自动描边。灯线颜色、线宽、光晕大小、强度和透明度都可调。
8. 点击“下载 1440×1440 PNG”，得到带准确中文文案、旧文字处理和氛围灯的成品主图。

图片、文案、横幅、拖动位置、清晰度、旧文字层（含原样抠字层）、局部改色和氛围灯线会自动保存到当前浏览器；刷新后会自动恢复。也可以点“保存当前设置”手动保存。换浏览器、换访问地址或清理浏览器数据后，保存记录不会保留。

图像模型直接写中文容易乱码，所以采用“无字底图 + 本地中文排版”的方式，字更清晰，也更方便反复改文案。

## 视频生成（Seedance）
1. 点击顶部“视频”添加视频节点，把图片节点连接到它的左侧输入端口。
2. 图生视频：第一张连接图作为首帧，其余图片作为参考图；填写镜头和动作提示词。
3. 视频编辑：把视频节点切换到“视频编辑”，连接一个上游视频节点，或粘贴公网可访问的 MP4 地址。
4. 选择清晰度、比例、时长和是否生成音频，点击“生成视频”。节点会显示任务状态，完成后可直接播放和下载。

底层调用火山方舟：
- 创建任务：`POST https://ark.cn-beijing.volces.com/api/v3/contents/generations/tasks`
- 查询任务：`GET https://ark.cn-beijing.volces.com/api/v3/contents/generations/tasks/{task_id}`

视频是异步任务，通常需要几十秒到几分钟。关闭页面只会停止前端轮询，不会取消方舟后台任务；再次打开页面不会自动恢复轮询，但已有结果 URL 会保留。

> Seedance 2.5 / 2.0 请优先填写火山方舟控制台里对应模型的 `ep-...` 推理接入点 ID。不同账号开通的模型和可用参数可能不同，若提示参数不支持，请改用控制台确认的模型/接入点。

## 常见问题
**提示 ModelNotOpen**

账号还没有开通该模型。到火山方舟控制台开通对应模型，或创建该模型的推理接入点，再把 `ep-...` 填进“图生图模型”。

**视频提示模型不存在 / 参数不支持**

确认设置里的“视频模型 / 接入点”是 Seedance 系列，而不是 Seedream 图像模型。Seedance 2.5 建议直接填控制台创建的推理接入点 ID。

**视频编辑没有源视频**

视频编辑需要公网可访问的视频 URL。图生视频节点生成的结果可以直接连到另一个视频节点的输入端口作为编辑源。

**提示缺少 API Key**

点击右上角设置填写密钥。密钥只保存在当前浏览器本地。

**点击运行提示 Failed to fetch**

通常是浏览器直接请求火山方舟时被跨域、VPN、代理或防火墙拦截。新版 `serve.mjs` 会自动把本地 `/ark-proxy` 请求转发到方舟；请关闭之前的命令行窗口，重新双击 `start-canvas.bat`，再刷新页面运行。若本机本身无法访问 `ark.cn-beijing.volces.com`，请检查网络、VPN 和代理设置。

**页面还是旧白板**

旧服务进程仍在提供旧代码。关闭之前的命令行窗口，重新双击 `start-canvas.bat`（静态版）或 `start-dev-vite.bat`；或确认浏览器刷新的是 `http://localhost:5180`。

**旧文字识别提示“识别失败”**

“识别旧文字”依赖本机 Windows OCR；识别失败不影响“原样抠字”。直接在右侧用“框选旧文字”框住旧字，再点“原样抠字”即可。如果提示 `/ocr` 不存在、`spawn EPERM` 或页面还是旧版，关闭当前服务窗口，双击 `open-canvas.bat` 让系统正常启动服务，再刷新页面。不要从 Codex 的受限终端里启动服务，否则 OCR 子进程会被沙箱拦截。

**启动时报 spawn EPERM**

Vite 的 `esbuild.exe` 被系统或安全软件阻止创建子进程。不要继续用 `start-dev.bat`，改用根目录的 `start-canvas.bat`。它是免构建静态版，只用 Node 自带 HTTP 服务器。

**图片太大**

应用会把最长边压到 4096px，并尽量保留细节；单张图片建议不超过 10MB。

## 构建与部署
```bash
npm run build
npm run preview
```

免构建静态版：
```bash
npm run build:native
npm run start:static
```

生成结果在 `native/`，可由 `serve.mjs` 直接提供，不依赖 esbuild。

产物在 `dist/`。Vercel / Netlify 导入仓库后选择 Vite。项目配置了相对资源路径，也可以部署到 GitHub Pages 子目录。

## 项目结构
- `src/WorkflowCanvas.tsx`：节点画布、拖拽、连线、运行与设置界面
- `src/workflow.ts`：节点模型、示例工作流、本地持久化
- `src/ai.ts`：方舟图像编辑、Seedance 视频任务、错误解析与设置存取
- `src/Icons.tsx`：内联 SVG 图标
- `src/styles.css`：深色节点画布界面
- `native/`：免构建静态版输出，由 `build-native.bat` 生成
- `public/main-image.html`：电商主图排版页面，独立于节点画布
